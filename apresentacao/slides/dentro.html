Dentro de cada serviço Java

domain

A regra do negócio, sem framework nenhum. Não conhece banco, HTTP nem fila.

application

Um caso de uso por operação, cada um com entrada e saída próprias.

infrastructure

Onde o mundo entra: rotas, banco, fila, armazenamento e segurança.

As dependências apontam para dentro: a infraestrutura conhece o domínio, e nunca o contrário. São módulos de build separados, então essa regra não depende de disciplina — o compilador a recusa.

6

Os pacotes são por agregado e papel, não por camada técnica: dentro de infrastructure existe video, category, genre — e não controllers, services, repositories. Abrir a pasta diz o que o serviço faz.
